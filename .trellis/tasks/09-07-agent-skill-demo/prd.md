# Agent Skill and Internal Demo

Deliver a distributable local-first Specialist OS agent skill, reduce discovery
and consecutive-call overhead, and prepare an internal engineering/product talk.
Fifteen minutes of slides and ten minutes of real end-to-end demonstration.

Acceptance: targeted capability discovery, reusable batch CLI execution with
structured failures, tested local installation guidance, measured timings,
full capability rehearsal command, timed speaker runbook, and a substantial editable deck.
All showcase results come from actual CLI execution. Download models on demand.

## ADR-003 demo refresh

Refresh real CLI E2E evidence after the Core freeze. Deliver a browsable local
demo with playable audio, a revised 15-minute deck retaining the transparent
Logo B and Hero A, and a 10-minute live runbook. Distinguish the 15 families
from their 56 APIs. Do not add spatial/generative providers. Failed or unavailable
capabilities must retain their actual status, and older evidence cannot count
as a fresh run. Preserve the existing published gallery while auditing locally.

## User-approved 3D evaluation extension

The user requested all three demonstration categories on 2026-09-07:
image-to-3D asset generation, photo-based scene geometry, and visualization of
existing calibration/PnP operators. Add explicit experimental CLI routes and
separate non-Core evidence. Keep Core admission and the 56-API baseline unchanged.

Acceptance: run one actual local provider per new category with pinned source
and weights, preserve input hashes, commands, device, timing and errors, export
viewable GLB/PLY artifacts, and verify interaction in a Three.js viewer on
desktop/mobile. Do not reuse upstream output demos. Distinguish generated assets,
estimated scene geometry, and calibrated algorithm examples in output semantics.
Update the live runbook and slides after verification. No paid or remote GPU
execution without a new user decision.
