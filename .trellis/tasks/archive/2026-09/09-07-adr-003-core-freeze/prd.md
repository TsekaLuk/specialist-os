# ADR-003 Core freeze

Implement the accepted 2026-09-07 scope decision. Preserve the current 56 API
contracts grouped into 15 product capability families. Existing depth aliases
and deterministic geometry stay supported. No new spatial or generative model
is requested. Core installation must not grow with future registry additions.

Acceptance: explicit Core baseline, accurate pack discovery with compatibility,
committed ADR and formal spatial watchlist, bilingual product scope and roadmap,
regressions for Core membership, pack/install boundaries and retained aliases.
Unassessed watchlist properties must remain unknown, not inferred benchmarks.
